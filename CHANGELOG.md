# Historial de cambios

Los cambios relevantes de Nimbo VPS se documentan aquí. El proyecto sigue [Semantic Versioning](https://semver.org/lang/es/) y Conventional Commits.

## [1.0.0] - 2026-09-02

### Añadido

- Landing de presentación y calculadora responsive de siete etapas.
- Estimación orientativa de CPU, RAM, almacenamiento y transferencia.
- Resumen explicado, comparación de escenarios y carta formal exportable.
- Nimbo como asistente animado, con consejos diferidos y movimiento reducido.
- Sistema local de iconos, marca, favicon y recursos reproducibles.
- Estado terminal que bloquea la edición tras finalizar la solicitud.
- Pruebas de lógica, layout, interacción, impresión y múltiples viewports.
- Build de producción y CI/CD para GitHub Pages.
